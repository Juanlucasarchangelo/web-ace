ACE CLOUD HUB V2 — 02/11/2026
===============================

ESCOPO
- Uma central de armazenamento com varias contas Google Drive por workspace.
- Selecionar conta na lateral; criar, entrar, mover, renomear e excluir pastas e arquivos.
- Duas visualizacoes (lista/grade), busca na pasta atual, detalhes, download e previa de PDF/imagens.
- Login via OAuth oficial Google (selecao de conta, sem capturar senha no ACE).
- iCloud e MEGA aparecem como expansoes FUTURAS: nao conectam nesta versao.
- Correcao de visibilidade das abas (Geral/Hospedagem/Loja & Redes/Acessos) em Sites.
- O backend atual e a conexao existente sao preservados: migration remove APENAS a restricao de uma conta por empresa.

PRE-REQUISITO
Este pacote e uma ATUALIZACAO do ACE com o "ACE-Drive-Manager-Update" anterior ja instalado.
Nao e um projeto Laravel completo. Nao sobrescreve .env, composer.json, Docker ou banco.

INSTALACAO (Windows / PowerShell)
1. Faça backup do MySQL antes de aplicar a migration (recomendado: dump testado).
2. Extraia esta pasta, por exemplo, em web-ace/ace-cloud-v2.
3. Dentro de web-ace, execute:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\ace-cloud-v2\INSTALAR-ACE-CLOUD-V2.ps1 -Projeto .
4. Recrie a imagem: docker compose up -d --build app web
5. Se o Docker nao aplicar as migrations automaticamente, execute:
   docker compose exec app php artisan migrate --force
6. Em caso de erro 502 apos recriar app:
   docker compose restart web
7. Recarregue http://127.0.0.1:8088/nuvem (Ctrl+F5) e teste.

TESTE SEGURO
- Confirme que sua conta Google atual continua listada com os arquivos.
- Clique Conectar conta; escolha UMA OUTRA conta Google no consentimento oficial.
- Confirme ambas na barra lateral e navegue entre elas.
- Crie uma pasta de teste; envie um arquivo; mova para essa pasta, renomeie e visualize.
- Em /sites, abra um site, clique Loja & Redes, role a lista e confirme que as abas continuam visiveis.

IMPORTANTE SOBRE O GOOGLE
A permissao atual drive.file mostra os arquivos criados ou autorizados especificamente para o ACE.
Nao existe acesso automatico a todos os arquivos antigos do Drive.
Mover arquivos ENTRE contas Google diferentes ainda NAO e suportado; mover DENTRO de uma conta e suportado.
A interface ja diferencia os provedores, mas iCloud/MEGA nao estao implementados.
Ate 10 MB por arquivo nesta versao, conforme a API ja existente.

SEGURANCA
- E-mails sao usados para diferenciar contas dentro do mesmo workspace.
- Tokens ficam cifrados no modelo existente GoogleDriveConnection.
- account_id e sempre validado contra tenant_id; outra empresa nao pode acessar conta alheia.
- Somente owner/admin podem conectar, desconectar ou editar arquivos (regra ACE existente).
- Provedor requer acesso autorizado na propria janela do Google. Nao solicite senha no ACE.
- Desconectar a conta no ACE nao apaga arquivos hospedados no Drive.
- O instalador cria backup dos arquivos alterados em .ace-backups/cloud-hub-v2-DATA.
